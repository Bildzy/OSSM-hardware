# Standard Build (WIP)

## Standard Build (WIP)

Welcome to the **Standard Build** documentation for the OSSM project. This is the recommended starting point for new users who want to build a fully supported OSSM using official R+D components.

> 🧪 This section is a work in progress. We’re currently improving structure, formatting, and content organization.

***

### 🔰 What is the Standard Build?

The Standard Build is the fastest way to get started. It’s a pre-defined configuration of OSSM that:

* Uses only official, ready-to-buy parts from R+D
* Avoids complex decision trees or variant options
* Has a fully tested and documented build process

Think of this as the **“golden path”** for beginners.

***

***

### 💡 Who Is This For?

This documentation is ideal if you:

* Are new to OSSM
* Want a frictionless start
* Prefer to buy a kit or verified components

If you plan to customize your build or print alternative components, check out the Variants & Custom Builds section (coming soon in Phase 2).
